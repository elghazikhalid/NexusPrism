# NexusPrism

NexusPrism is a distributed real-time data processing engine that enables scalable, on-demand infrastructure for high-performance applications.

NexusPrism is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/NexusPrism.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure NexusPrism, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
